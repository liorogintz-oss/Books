# ספריית הבית

קטלוג ספרים משפחתי: מקלידים ISBN והפרטים והכריכה מתמלאים (Google Books / Open Library), וכל אחד מהבית — רביד, עדי, קרן וליאור — רושם סטטוס קריאה, דירוג וחוות דעת.

- `app.html` — מקור הדף (כפי שמתפרסם כ־Artifact ב־claude.ai, עם קטלוג משותף).
- `index.html` — אותו דף כקובץ עצמאי, לאירוח ב־GitHub Pages. בגרסה הזו הנתונים נשמרים בדפדפן, ויש גיבוי ושחזור לקובץ.
